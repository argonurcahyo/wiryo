# public/icons/

Place your PWA icon files here.

Recommended filenames (referenced in app/manifest.ts):

  icon-192x192.png  –  192 × 192 px  (maskable, for Android home-screen)
  icon-512x512.png  –  512 × 512 px  (splash screen / install dialog)

Quick generation:
  1. Visit https://realfavicongenerator.net or https://favicon.io
  2. Upload a square PNG (1024 × 1024 recommended)
  3. Download the package and copy the 192 & 512 variants here

Optional extras:
  apple-touch-icon.png  –  180 × 180 px (iOS Safari "Add to Home Screen")
